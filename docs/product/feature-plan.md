# Launcher3 → Pixel → Mandre Launcher roadmap

112 capability rows, derived from the MVP research. This is a scoped inventory of audited user capabilities/source paths, not every hidden Google feature or dormant AOSP flag. Source presence does not imply standalone runtime availability. **All production entries are planned, not implemented or certified.**
